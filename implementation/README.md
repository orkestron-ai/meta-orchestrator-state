# Implementation — the Orkestron-based simulation realization

This directory is **one realization** of the [`../methodology`](../methodology): the
**executable simulation** of a Meta-Orchestrator State, populated by 2,000–3,000 AI-agent
citizens, running on the Orkestron stack. It is the *experiment* — the methodology is the
*transferable model*. A real-world MOS would reuse the methodology but replace everything
here (AI-agent citizens → human citizens, sim-clock → real time, Agent Hub → real civic
infrastructure).
