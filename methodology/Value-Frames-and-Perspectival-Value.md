> **The realization:** value is **perspectival**, not objective. Each citizen, family,
> business, and the state has its *own* valuation of the same activity. The worry — "does
> it all converge to a mega-graph with the **state at the apex**? :(" — is resolved here,
> using VMT's own axioms: **that apex is theoretically impossible.** MOS is a **federation
> of value systems**, not one state-owned ledger.

## 1. Perspectival value is VMT's foundation, not a complication

| VMT | Statement | Consequence for MOS |
|---|---|---|
| **A1 Context** | value is defined *only* within a value system | there is no single "MOS value"; only value *within a frame* |
| **A2 Multiplicity** | one reality → different values in different systems | citizen / family / business / state each value the same act differently — **keep them separate** |
| **T1** | "value-in-general" does not exist | you *cannot* sum all frames into one number |
| **T2 Inversion** | one flow, opposite interpretations across systems | vote-vs-spend, profit-vs-civ-value are inversions, not errors |
| **A12 No conservation** | value appears/disappears with context | value cannot be "collected" into one pot |
| **A13 Partial commensurability** | values may be commensurable, partial, or not | the 10 axes are a *shared vocabulary*, enabling **partial** comparison only |

### The value system = the "frame of reference"
VMT's **Value System = {A, F, G, R, T}** (actors, flows, improvement/degradation criteria,
interpretation rules, time horizon; boundaries set by the choice of A and F) **is** the
frame. In MOS:

- a **citizen** is a value system (own G/R = own preferences);
- a **family** is a value system (the head's "everyone gets along" = the family's G/R);
- a **business** is a value system (the director's "reward contribution to the company" = the company's G);
- the **state** is a value system **too** — with a *specific, bounded mandate*: civilizational balance, per-cohort floors, externalities across the network.

The same action has a different value in each (A2/T2). **MOS records value per frame and
does not collapse them.**

## 2. The mega-graph has NO apex — and that's forced, not chosen

The fear: everything sums upward to the state → re-centralization (the very thing the
project opposes). VMT makes that apex **theoretically invalid**:

- **No value-in-general (T1) + context (A1) + multiplicity (A2)** → summing all frames into
  one state-owned scalar is a category error.
- **No conservation (A12)** → value can't be aggregated into one pot across contexts.
- **Inter-system only via external flows (A10)** → systems touch only at their **boundaries**;
  the state **does not contain** the family's internal graph — it sees only flows that
  cross the boundary. (Change the boundary and conclusions change without reality changing — **T15**.)

→ The correct picture is a **federation of peer value systems** (polycentric — cf. Ostrom),
where the state is **one frame with a narrow mandate** (fairness / floors / externalities
*across* the network), **not the integrator** of all others. Monocentric convergence-to-the-
state is the theoretically broken picture. The apex you feared is one your own theory
forbids — and its absence *is* the anti-concentration ethos applied to value itself.

## 3. Where frames meet — reconciliation operators, in VMT terms

We already built these; here are their canonical names:

| Operator | VMT basis | MOS mechanism |
|---|---|---|
| **Planned vs Realized gap** | A4 asymmetry, T3, **Flow Resistance** (T4, accumulates) | claimed-vs-attested; over-claiming = resistance that costs TrackRecord |
| **Cross-system inversion** | T2 | vote-vs-spend, profit-vs-civ-value — measured both ways, not forced to agree |
| **Externality overlay** | flows external to the private deal but **internal to the state frame** | multidimensional Pigou (`Markets-and-Civilizational-Value.md`) |
| **Participation condition θ** | A8, A9 (sustainable ⇔ all θ met), T7 (θ violated → actor exits/changes) | **the formal alarm for "state policy is making citizens deeply unhappy / destroying a business."** The state *must* monitor θ for every actor, because its own system is unsustainable if any θ fails |
| **Leakage** | A11, T9 (hidden flows) | a region/business where realized value persistently exits the frame |
| **Courts** | A2 + interpretation rules R | when frames conflict irreconcilably (`Courts-and-Adjudication.md`) |

**Key reframe of the owner's worry:** "it's important to know when the state's goals make
some citizens miserable or destroy a business" is **A9 + T7** — a *sustainability theorem*,
not an afterthought. Monitoring participation conditions across all actors is a
first-class state duty, alongside floors.

## 4. The family, worked through VMT

The family is a value system with internal flows (harmony = its G; internal demand;
internal anti-value = conflict = flow resistance). By **A10**, the state interacts with the
family **only at the boundary** — it neither sees nor governs the inside (subsidiarity +
privacy). It **senses** family health via *external* signals (demographic output, wellbeing
attestations, rising meaning-anti-value) and the family's **participation condition**, and
it **generates demand** (support, incentives) to lower the family's internal flow
resistance. If the state wants population growth, it must keep the family's θ satisfied
**from the family's own frame** — never impose the state's frame inside the family. That is
how "the internal life of families matters" is accounted for **without surveilling the
dinner table.**

## 5. What this refines in the prior blocks

- **The 10 axes are a *shared vocabulary*** (partial commensurability, A13) — **not** a
  single objective scale. Each frame carries its **own weights / criteria (G) / interpretation
  rules (R) / boundaries (A,F)** over that vocabulary.
- **The voted `w(t)` is the *state frame's* weights** — the civilizational/collective frame —
  **not "the" weights.** Citizens have their own (revealed by spend); businesses their own.
  The state uses its weights only to compute *its* imbalance and apply *its* overlay.
  (Refines `Value-Axes-Corridors-Voting.md`.)
- **The single "Æ-ledger" is really a federation of per-frame ledgers** that meet only at
  external flows. The state ledger books only what crosses into the state's frame.
