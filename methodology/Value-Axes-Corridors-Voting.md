### Cross-cutting constructs — NOT axes (design discipline)
> *Axes are what you trade off via weights. What must never be traded off is a
> constraint/guardian, not an axis.*

- **Equity (distributional fairness)** → a **floor-protected constraint + Ombudsman/Equity
  Sub-Agent**, never a votable axis. (Else the majority could "trade away" fairness.)
- **Generosity (solidarity)** → a **flow type** (donated, un-consumed value books bonus Æ
  on `meaning`+`social_stability`), not an axis.

## 2. Corridors — per axis, per cohort, per region

Each axis carries three thresholds:

| Threshold | Meaning | Who can change it |
|---|---|---|
| **floor** | constitutional minimum; below = high-priority imbalance | **supermajority + affected-cohort veto** (not ordinary vote) |
| **target_band** | where the state keeps the axis; weights steer emphasis *within* it | ordinary process |
| **ceiling** | soft cap; above it marginal value is discounted (anti over-optimization; the economic ceiling = concentration self-charge) | supermajority |

Governance = keep every axis within `[floor, ceiling]` **for every cohort**, and steer
*emphasis* inside `target_band` via voted weights.

## 3. Voting on weights — liquid democracy

Citizens distribute a **priority budget** (e.g. 100 points) across the 10 axes.

- **Quadratic cost** on concentrating budget into one axis (cost of `k` points on an axis
  = `k²`): intensity can be expressed but at rising cost → dampens single-issue capture,
  spreading is cheap.
- **TrackRecord-weighted, capped:** citizen voting weight `v_i = f(TrackRecord)` but capped
  at `v_max` (anti-concentration, Principle 7).
- **Party delegation (revocable, topic-scoped):** a delegated citizen's budget flows to the
  party's allocation for the delegated axes only; **party's accumulated delegated weight is
  quadratically discounted past a threshold** (no dictator-by-accumulation). Bounded
  transitivity depth.
- **Reproducible tally:** publish pseudonymous votes + aggregation-function commit-hash +
  resulting `w(t)` delta; any citizen can replay the count.

Output: normalized weight vector **`w(t)`**.

## 4. The imbalance signal (what Sub-Agents act on)

For axis `a`, cohort `c`, region `r`:

```
imbalance(a,c,r) =  w_a · distance( current_Æ(a,c,r), target_band(a,c,r) )   # steering, weight-scaled
                  + below_floor_penalty(a,c,r)        # LARGE; NOT scaled by w_a
                  + variance_penalty(a, across cohorts) # equity guardian; NOT scaled by w_a
```

**The crucial property:** the below-floor and equity penalties are **not multiplied by the
voted weight**. So the majority can downvote a minority's *emphasis* but **cannot vote a
cohort's floor into irrelevance**. Voted weight modulates steering only *within the band*.
This is the mathematical form of Principle 10 (minority protection) — the system literally
**cannot read "balanced" while any cohort is below floor**, regardless of headcount.

## 5. Stability guards

- **Hysteresis / change-rate limit:** `w(t)` may not swing more than X%/period; floors
  change only slowly + by supermajority. Resolves the stability-vs-adaptability dilemma →
  no policy whiplash.
- **Steer on settled value:** imbalance is computed primarily on *settled* Æ + trends;
  *provisional* value is down-weighted (don't act hard on un-attested value).

## 6. Bootstrap (cold-start legitimacy)
Initial floors/ceilings/weights are **constitution-seeded** (operator/owner sets them for
P0) and explicitly flagged **provisional until the first citizen vote** ratifies or revises
them.
