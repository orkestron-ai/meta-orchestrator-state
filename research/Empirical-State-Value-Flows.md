# 6. Distinctive value-flow *architectures* (models — for design reference)
Not a value-type taxonomy; these show that the **same needs are serviced by very different flow structures** — the design space Axiacracy sits in:
- **Nordic universalism** [SE] — unconditional universal benefits (child allowance, parental leave), high tax, near-total data legibility, active-labour activation. *Value returned = service breadth, not cash.*
- **Forced-savings / self-reliance** [SG] — mandatory individual accounts (CPF/MediSave), owned assets (HDB), dollar-matched co-payments, minimal unconditional transfer; **citizen savings fund the sovereign investor (GIC/Temasek).**
- **Digital state** [EE] — value delivered as **digital identity + interoperable infrastructure + once-only + i-voting + e-residency**; reciprocal input = data trust. The state even *sells* its apparatus (e-Residency).
- **Rentier / distributive** [Gulf] — **no income tax**; dividends, free housing/land, subsidized utilities, guaranteed public jobs from resource rent; reciprocal = **loyalty + closed citizenship**.
- **Directed / registration-tiered** [CN] — services gated by **hukou**; dibao safety net; **social credit as a state↔citizen information flow** (behaviour-for-privileges); migrant labour subsidizes the system.
- **Biometric direct-transfer** [IN/BR] — **Aadhaar/biometric ID rail** + Direct Benefit Transfer + conditional cash transfers (school/vaccine); reciprocal = biometric legibility + conditionality.
- **Wellbeing / discretionary-benevolence** [Bhutan] — value measured as **Gross National Happiness** across 9 domains; **Royal Kidu** discretionary welfare; reciprocal = loyalty + environmental/cultural stewardship.

# 7. Observations for the VSS (light, not yet the taxonomy)
Marked as raw observation only — grouping/classification is deferred per the owner.
- **State→citizen flows recur in a few *forms*** across all countries: cash transfer · in-kind service · **risk-pooling insurance** (health/pension/unemployment/care) · price subsidy · **legal right/protection** · infrastructure/access · **identity & information** · guarantee · **forced-savings account** · **dividend**. (Candidate flow-archetypes for later.)
- **Flows are life-cycle-conditioned** — the state services the citizen across the whole arc: birth → child → student → worker → parent → unemployed/disabled → pensioner → death. (Maps directly onto the MOS citizen life-cycle.)
- **Reciprocal citizen→state value is overwhelmingly *non-monetary*** (labour, service, data, legitimacy, compliance, reproduction, trust, stewardship) — exactly the multidimensional value GDP/tax accounting misses, and the point of Axiacracy's Æ-vector.
- **The external boundary is confirmed real & large**: resources, trade, aid, **diaspora remittances**, FDI, bond markets — the VSS must include it.
- **Business↔state is a dense two-way channel** beyond tax: the state provides finance/legal-order/infrastructure/data/procurement; business provides jobs/data/compliance/innovation/critical-infrastructure/mobilization.
